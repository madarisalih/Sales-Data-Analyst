# Sales-Data-Analyst

📊 Sales Dashboard – Excel Analytics
An interactive Sales Dashboard built in Microsoft Excel to analyze sales performance by product, region, and month.

🖼️ Dashboard Preview

✨ Features
📅 Date Filter – Analyze sales across different months and years.

🌍 Region Filter – Filter results by:

East

West

North

South

🖥️ Product Filter – Analyze:

Keyboard

Monitor

Mouse

Printer

Scanner

Speaker

💰 Total Amount – Displays total sales amount.

🧾 Total Sales – Displays the number of sales transactions.

📈 Sales by Month – Monthly sales trend visualization.

📊 Sales by Product – Percentage contribution of each product.

🌎 Sales by Region – Regional sales comparison.
